# 東松山バス あと何分？ (PWAアプリ)

東松山駅〔東口〕〜パークタウン五領線のバスが「あと何分何秒で来るか」を開いた瞬間に確認できる、シンプルで高速なPWA（Progressive Web App）アプリです。

## ✨ 特徴
- **開いた瞬間わかる**: 余計な操作なしで、次のバスまでの残り時間が秒単位でカウントダウンされます。
- **完全オフライン対応**: 時刻表データをアプリ内に内蔵しているため、電波の悪い場所や速度制限下でも爆速で起動します。
- **選べる行き・帰り**: 「駅へ行く」「帰る」を手動で切り替えられます。選んだ方向を端末に保存するため、次回も同じ方向で起動します。初回は「駅へ行く」です。
- **グリーンの見やすい画面**: 次のバスまでの時間を大きく表示。発車3分前からカウントダウンカードがオレンジ色に変わります。
- **後続便も確認**: 次のバスに加えて、そのあとの2便を表示します。
- **スマホ向け時刻表画面**: 「時刻表を見る」から専用画面に移り、行き・帰りと平日／土日祝を切り替えて確認できます。
- **祝日の自動判定**: 2026年・2027年の祝日と振替休日、お盆（8/13〜16）、年末年始（12/30〜1/3）に対応しています。

## 🚌 時刻表について

- 川越観光自動車「東松山駅〜パークタウン五領線」の2024年3月24日改正時刻表をもとにしています（2026年11月21日に照合）。
- 平日と土日祝日は便数が異なります。時刻表が改正されたときは `app.js` を更新してください。
- 祝日判定は現時点で2027年までの公表済み日付に対応しています。2028年以降の祝日は追加更新が必要です。
- バスの実際の到着状況を測るものではなく、予定時刻までのカウントダウンです。

公式時刻表: https://www.kawagoebus.jp/cms-pdf/topics/20240307090543pXpt2rY_tApZibJv09GSxA.pdf

## 📁 フォルダ構成
GitHubリポジトリには、以下のファイルがすべて同じ階層（ルートディレクトリ）に並んでいる必要があります。

```text
├── index.html        (画面の骨組み)
├── style.css         (デザイン・改行防止設定)
├── app.js            (時刻表データとカウントダウン処理)
├── manifest.json     (PWAの設定ファイル)
├── service-worker.js (オフライン起動のためのキャッシュ制御)
├── icon-192.png      (ホーム画面用アイコン 192x192)
├── icon-512.png      (ホーム画面用アイコン 512x512)
└── icon.html         (アイコン作成用ファイル)
```
